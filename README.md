# Fernwick — оригінальний шаблон (без змін)

Безкоштовний HTML-шаблон інтернет-магазину кімнатних рослин **Fernwick — Plant Shop Ecommerce Template** від [html.design](https://html.design/), завантажений без жодних змін (папка `fernwick-original`).

На його основі створено навчальний лендінг **Fernwick Україна**:

- відредагований лендінг: https://nazarenko228.github.io/fernwik/fernwick/
- репозиторій лендінгу: https://github.com/Nazarenko228/fernwik

Виконала: Назаренко Кіра, група 36/1, ОНЕУ, спеціальність «Маркетинг».
